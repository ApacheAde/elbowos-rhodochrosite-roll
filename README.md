# Rhodochrosite Roll

Full-colour Python 3 neon pinball arcade for ElbowOS.

Steer the ball with left and right flippers. Hit pink bumpers for score. Don't let the ball drain.

Left / A flip left. Right / D flip right.

## Play

```bash
pip install -r requirements.txt
python3 rhodochrosite_roll.py --play
```

## Record a 9:16 reel

```bash
python3 rhodochrosite_roll.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.

* Featured account: https://x.com/ElbowOS
